## 📖 About This Portfolio

This portfolio reflects the **"Concept Extension"** philosophy at the heart of ECON 5200:

> *We don't abandon classical econometrics — we scale it.*

Each lab and project takes a foundational statistical concept from economics and extends it using contemporary data science methods:

| Classical Concept | Modern Extension |
|---|---|
| OLS Regression | Lasso / Ridge Regularization |
| Hypothesis Testing | Bootstrap & Permutation Methods |
| Structural Estimation | ML-Augmented Causal Inference |
| Time Series (ARIMA) | Gradient Boosting Forecasters |

The goal is to develop fluency in **both** languages: the causal inference toolkit that economists trust, and the predictive analytics toolkit that data scientists rely on. The most interesting problems live at the intersection.
